# Администратор гостиницы

Курсовая работа по дисциплине «Технологии программирования».

## Описание

Настольное приложение для администратора (ресепшн) и управляющего небольшой гостиницы. В нем ведется номерной фонд (класс номера, число мест), бронирование, регистрация гостей с паспортными данными, поселение с выбором подходящего номера по свободным местам, выписка с расчетом задержки выезда и досрочный отъезд с перерасчетом. На каждую оплату или возврат оформляется квитанция.

## Функциональность

- список номеров с классом, числом мест и занятостью на сегодня (проживает, забронировано, свободно);
- подбор номера по датам, классу и числу мест — только номера со свободными местами на весь срок с учетом проживающих и броней;
- бронирование мест на будущие даты, изменение и отмена брони; список «Заезд сегодня»; автоматический незаезд;
- регистрация гостя (ФИО, дата рождения, гражданство, паспорт: серия и номер, кем и когда выдан, телефон) с проверкой данных; повторный гость находится по паспорту;
- поселение по брони или без брони, одного или нескольких гостей; квитанция на оплату проживания;
- список гостей с паспортными данными, датами приезда и отъезда и номером, фильтр «проживают / выехали / все»;
- поиск гостя по произвольному признаку: по любому полю (фамилия, паспорт, номер, даты, гражданство, телефон…) или по всем полям сразу;
- «Отъезд сегодня»: отъезжающие сегодня и не выехавшие в срок; выписка с освобождением места;
- задержка выезда после расчетного часа 12:00 (до 18:00 — 50 % суток, позже — полные сутки) с дополнительной квитанцией;
- продление проживания с проверкой свободного места и квитанцией;
- досрочный отъезд с перерасчетом и квитанцией на возврат;
- предварительный просмотр и печать квитанции; реестр квитанций за период с итогами;
- справочник номеров и тарифов (цена за место в сутки по классу номера);
- вход по логину и паролю, две роли (администратор, управляющий); пароли хранятся только в виде хеша PBKDF2 с солью;
- хранение данных в JSON-файлах, восстановление при повреждении файла, журнал действий пользователя.

## Технологии

- C# 13, .NET 9
- Windows Forms, паттерн Model-View-Presenter (пассивное представление)
- xUnit — модульные тесты ядра и презентеров
- анализаторы .NET, `.editorconfig`, `dotnet format` — предупреждения считаются ошибками
- Visual Studio 2022

Архитектура и примененные паттерны описаны в [docs/plan.md](docs/plan.md#6-устройство-программы), диаграмма классов — в [docs/class-diagram.md](docs/class-diagram.md), тест-кейсы — в [docs/test-cases.md](docs/test-cases.md).

## Структура

```
src/Hotel/              приложение Windows Forms: формы (Forms), интерфейсы представлений (Views), презентеры (Presenters)
src/Hotel.Core/         бизнес-логика без зависимости от Windows Forms: модели, занятость, расчет, сервисы, хранение
tests/Hotel.Tests/      модульные тесты
tools/                  ui-smoke.ps1 — автоматическая проверка форм со скриншотами
docs/                   план, требования, тест-кейсы, диаграмма классов, скриншоты
```

## Запуск

Нужен [.NET SDK 9](https://dotnet.microsoft.com/download) и Windows.

```
dotnet run --project src/Hotel
```

Тесты и проверка стиля:

```
dotnet test
dotnet format --verify-no-changes
```

Проверка всех форм со скриншотами:

```
powershell -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -OutDir docs/screenshots
```

При первом запуске создаются демонстрационные данные (даты отсчитываются от сегодняшней): 12 номеров на трех этажах, тарифы, 7 гостей, проживающие (в том числе отъезжающие сегодня и не выехавший в срок), 4 брони (две — с заездом сегодня) и учетные записи:

| Логин | Пароль | Роль |
|---|---|---|
| `manager` | `manager123` | Управляющий: все функции, номера, тарифы, квитанции за период, пользователи, журнал |
| `admin` | `admin123` | Администратор: бронирование, поселение, выписка, продление, поиск гостей, квитанции |

Данные хранятся в папке `data` рядом с программой, журнал — в `logs/app.log`.
